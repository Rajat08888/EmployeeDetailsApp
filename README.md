# EmployeeDetailsApp

EmployeeDetailsApp is an employee management application designed to manage employee information in a simple and organized way.

## 🚀 Features

* Add new employees
* View employee details
* Update employee information
* Delete employee records
* Employee listing
* Employee data management
* User-friendly interface
* Database-driven employee records

* **.NET / ASP.NET**
* **HTML5**

* **JavaScript**
* **Bootstrap**

## ⚙️ Getting Started

### Prerequisites

Make sure the following are installed:

* Visual Studio
* .NET SDK compatible with the project
* SQL Server
* Git

### 1. Clone the Repository

```bash
git clone https://github.com/Rajat08888/EmployeeDetailsApp.git
```

Navigate to the project:

```bash
cd EmployeeDetailsApp
```

### 2. Open the Project

Open the solution/project in Visual Studio.

```text
EmployeeDetailsApp.sln
```

### 3. Configure Database

Update the database connection string according to your local SQL Server configuration.

Example:

```json
{
  "ConnectionStrings": {
    "DefaultConnection": "Server=YOUR_SERVER;Database=EmployeeDetails;Trusted_Connection=True;TrustServerCertificate=True;"
  }
}
```

### 4. Run the Application

Run the application from Visual Studio or use:

```bash
dotnet run
```

The application will start on the local development server.
